## Why this exists

`craftblob` is a purpose-built `text` toolkit: Craft and reshape blob text streams with deterministic transforms.

- Zero runtime dependencies
- Library API + stdin-friendly CLI
- Local-first (no network, no telemetry)
- Docs site on GitHub Pages

## Quick start

```bash
git clone https://github.com/theworker02/craftblob.git
cd craftblob
node --test
node src/cli.js
```

Live docs: **[https://theworker02.github.io/craftblob/](https://theworker02.github.io/craftblob/)**
